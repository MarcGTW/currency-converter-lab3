# Отчёт · Лабораторная работа №3

Дата подготовки: 21.10.2026. Вариант: конвертер валют. NASA NEO Tracker не реализовывался.

## 1. Источник и обоснование

Выбран бесплатный Frankfurter v2 с ограничением `providers=ecb`. Он даёт JSON без API-ключа, фактическую дату наблюдения и позволяет запрашивать исторические данные. Кэширование разрешено документацией. Провайдер ECB выбран, чтобы курсы происходили из одного официального источника. Используется 10 валют из покрытия ECB; наличие MDL/RUB не заявляется.

Реальный запрос на воскресенье 18.10.2026 вернул массив за пятницу 16.10.2026. Это проверено до реализации загрузчика. Позднее в GUI за 21.10.2026 получен последний опубликованный курс от 20.10.2026; приложение вывело предупреждение, не выдало его за сегодняшний. Источник: https://frankfurter.dev/ (проверен 21.10.2026).

## 2. Инструменты и модели

В этой сессии спецификации, реализация и тесты подготовлены агентом Codex. Точное пользовательское обозначение модели не подтверждено и не выдумывается.

**Google Antigravity не запускался; модели Antigravity не использовались. GitHub Copilot и CLI Spec Kit не запускались.** Markdown-файлы в структуре Spec Kit подготовлены непосредственно Codex по заданию. Следовательно, этот репозиторий — рабочая заготовка, а не подтверждение полного требуемого процесса. Инструкция реального прохождения находится в docs/ANTIGRAVITY.md.

## 3. Что получилось с первой попытки

- Загрузчик соответствует проверенному реальному JSON-контракту Frankfurter v2.
- GUI отображает источник и фактическую дату, блокирует отрицательную сумму, понимает десятичную запятую.
- Прямой и обратный расчёт проверены в браузере: по курсу 1 EUR = 1,1215 USD получены 112,15 USD за 100 EUR и 89,17 EUR за 100 USD.
- Первый запуск набора из 22 тестов прошёл без падений.
- Кэш восстановился после остановки и повторного запуска локального сервера и перезагрузки страницы; при недоступном источнике потребовалось явное нажатие кнопки.

## 4. Ошибки, расхождения и исправления

1. **Погрешность в одинаковых валютах.** При дополнительном числовом контроле обнаружено: первоначальная общая формула давала `0.010000000000000002` для 0,01 USD → USD при курсе 1,1253. Хотя при отображении это округлялось до 0,01, спецификация требует вернуть исходную сумму. Codex добавил отдельный возврат суммы при одинаковых валютах и регрессионную проверку. Исправление внесено напрямую в public/core.js, а не агентом Antigravity.
2. **Ошибки работы с Git в изолированной среде.** Первые команды столкнулись с разным владельцем папки и запретом записи .git. Они не создали коммитов. Повторный запуск с разовым параметром safe.directory и разрешением записи создал нормальную историю. Глобальная конфигурация Git не менялась, даты коммитов не подделывались.
3. **Расхождение с обязательными инструментами.** Полный цикл Copilot → Antigravity не выполнен. Документы нельзя выдавать за артефакты, сгенерированные этими инструментами. Нужен реальный запуск по инструкции и дополнение данного раздела фактическими ошибками Antigravity.
4. **Нет удалённого репозитория и PR.** Локально есть три ветки этапов, но GitHub origin не задан. PR и слияния main не заявляются; это остаётся незавершённой частью приёмки.

Пользователь вручную код не редактировал. Изменения и исправления выше выполнены Codex; утверждений о несуществовавших действиях человека нет.

## 5. Соответствие исходной спецификации

FR01–FR14 реализованы: GUI, проверка суммы и даты, направления конвертации, источник, выходные/пустые данные, явный выбор кэша, сохранение, защита от будущего кэша и сброс устаревшего результата. Исторические курсы ограничены покрытием выбранного провайдера; отсутствие нужной валюты обрабатывается сообщением.

Приёмка процесса выполнена частично: отдельный новый локальный Git-репозиторий, спецификации перед кодом и раздельные ветки есть; официальный запуск Spec Kit/Copilot, реализация через Antigravity и реальные GitHub PR ещё требуют выполнения. По этим причинам полная сдача лабораторной не заявляется.

## 6. Проверки

`npm test`: 22 теста, 22 успешных. Запускаются без сети. Есть unit-тесты парсера, расчёта и валидации, тесты загрузчика с подставным fetch, тесты постоянного storage и HTTP smoke-тесты локального сервера.

В настоящем браузере проверены реальный ответ источника, прямой/обратный расчёт, перестановка валют со сбросом результата, одинаковые валюты и запятая, блокировка -10, предупреждение о дате. Проверен сценарий перезапуска: реальный успешный ответ сохранён → сервер остановлен → сервер запущен с тестовым загрузчиком, возвращающим сетевую ошибку → страница перезагружена → кэш предложен → после нажатия расчёт работает, режим «Сохранённый курс». Системный сетевой адаптер при этом не отключался; сетевые исключения и таймаут отдельно проверены unit-тестами. Для более старой даты 18.10.2026 кэш от 20.10.2026 не предложен.

Мобильная компоновка просмотрена в узкой панели браузера. Полный прогон по разным браузерам и реальный офлайн без адаптера не выполнялись. Снимок: docs/cache-preview.png.
