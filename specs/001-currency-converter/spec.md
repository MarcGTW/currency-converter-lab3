# Спецификация: конвертер валют

Статус: согласованная исходная спецификация до реализации, подготовлена Codex.

## Пользовательские истории

- US1 (P1): пользователь вводит сумму, выбирает две валюты и получает результат с датой и источником.
- US2 (P1): пользователь без сети может явно выбрать последний сохранённый курс после перезапуска.
- US3 (P2): пользователь выбирает историческую дату и видит последний опубликованный курс не позже этой даты.

## Требования и приёмочные сценарии

| ID | Требование | Проверка |
|---|---|---|
| FR01 | Сумма, исходная и целевая валюты, кнопка и результат | Все элементы доступны в браузере |
| FR02 | Пустое поле, ноль, отрицательные значения, буквы, NaN и бесконечность запрещены | Кнопка неактивна, текст ошибки у поля |
| FR03 | Разрешены точка или запятая как десятичный разделитель; максимум 2 знака и сумма до 1 трлн | Проверка границ, смешанных разделителей и научной записи |
| FR04 | Конвертация через общий базовый EUR: amount / rates[from] * rates[to] | Прямое, обратное и перекрёстное направления |
| FR05 | Одинаковые валюты возвращают исходную сумму без ошибки | EUR → EUR |
| FR06 | Источник Frankfurter v2, провайдер ECB. 10 валют: EUR USD GBP CHF JPY CAD AUD CNY PLN SEK | Ответ проверяется до использования |
| FR07 | По умолчанию сегодняшняя локальная дата; допустим диапазон 1999-01-04…сегодня | Невозможные и будущие даты не отправляются |
| FR08 | Дата ответа и ссылка на источник видимы рядом с результатом | Дата не подменяется датой запроса |
| FR09 | Для выходного/праздника берётся последняя доступная дата ≤ запрошенной | Явное предупреждение; при пустом ответе поиск назад до 10 дней |
| FR10 | Таймаут/HTTP/некорректный ответ показывают ошибку; при наличии кэша — кнопку его использования | Кэш никогда не применяется молча |
| FR11 | Последний валидный ответ сохраняется в localStorage и переживает перезапуск браузера/сервера | После обновления страницы при сбое сети доступен кэш |
| FR12 | Повреждённое/недоступное хранилище обрабатывается без падения | Сообщение, работа в памяти; неверный кэш не используется |
| FR13 | Изменение даты, суммы или валют скрывает устаревший результат | Результат соответствует текущему вводу |
| FR14 | Кэш с датой позже выбранной не предлагается для исторического запроса | Нет подмены истории будущим курсом |

## Границы

Курс справочный, без комиссий. Округление только при отображении, 0 знаков для JPY, 2 для остальных. Нет авторизации, оплаты, MDL или RUB: они не входят в выбранный набор ECB. При старых датах отдельная валюта может быть недоступна — показать ошибку, не придумывать курс. Для одинаковых валют также требуется загруженный набор курсов, чтобы источник и дата оставались единообразными.

## Критерий завершения

Приложение запускается одной командой, unit-тесты проходят одной командой. Сценарии сети и перезапуска описаны в README. Учебный процесс Copilot → Antigravity и публикация PR подтверждаются отдельно; наличие кода не подтверждает их выполнение.
