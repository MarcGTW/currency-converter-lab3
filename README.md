# Лабораторная работа №3: Трекер околоземных астероидов (NASA NEO Tracker) & Конвертер валют

Двухрежимное локальное веб-приложение с графическим интерфейсом космической тематики, созданное в соответствии с методологией **Spec-Driven Development (SDD)** с использованием **GitHub Spec Kit** и **Google Antigravity** (модель **Gemini 3.8 Flash**).

---

## Варианты и состав приложения

В приложении полностью реализованы два режима работы с удобным переключателем в верхней панели:
1. **🚀 NASA NEO Tracker (Околоземные астероиды)** — целевой вариант задания:
   - Источник: официальный REST API **NASA JPL NeoWs (Near Earth Object Web Service)** (`/feed`).
   - Мониторинг астероидов на выбранную дату: минимальный/максимальный диаметр (м/км), скорость сближения (км/с и км/ч), расстояние сближения (км и лунные дистанции LD), точное время пролёта.
   - Идентификация потенциально опасных объектов (`is_potentially_hazardous_asteroid === true`) с визуальной световой индикацией и фильтром тревоги.
   - Сортировка по расстоянию, размеру, скорости или имени, а также мгновенный поиск.
   - Автоматическое сохранение снимка в `localStorage`, поддержка работы без сети (offline fallback) и обработка пустых дней с подтягиванием последнего доступного кэша.
2. **💱 Конвертер валют (ECB / Frankfurter)** — базовый лабораторный модуль:
   - 10 валют по официальным справочным курсам Европейского центрального банка (ECB).
   - Поддержка десятичных точек и запятых, защита от некорректного ввода, перестановка валют (swap), сохранение в локальный кэш.

## Быстрый запуск

Требуется **Node.js 22+** (без внешних зависимостей, чистая стандартная библиотека Node.js). `npm install` не требуется.

```powershell
# Переход в директорию проекта
cd "C:\Users\Marc\Desktop\konvert valute"

# Запуск локального сервера
npm start
```

После запуска открыть в браузере: **http://127.0.0.1:3000**

Если порт 3000 занят, можно указать другой порт:
```powershell
$env:PORT = '3001'
npm start
```

## Тестирование одной командой

Все unit- и интеграционные тесты запускаются стандартным раннером `node --test` без необходимости подключения к сети:

```powershell
npm test
```

### Покрытие тестами (31 тест, 100% pass):
1. **Календарная валидация дат**:
   - Астрономический расчет високосных лет (2024 — да, 2026 — нет, 1900 — нет, 2000 — да).
   - Защита от несуществующих календарных дат (29 февраля 2026 г., 31 февраля, 31 апреля, неверный формат).
   - Граничные диапазоны (`1900-01-01` .. текущая дата).
2. **Разбор контракта NASA NeoWs API**:
   - Извлечение характеристик астероидов, классификация потенциальной опасности (PHA).
   - Расчет и форматирование диапазонов диаметра, скоростей и лунных расстояний.
   - Обработка пустых дней (`element_count: 0`).
   - Обработка поврежденных или неполных ответов.
3. **Фильтрация и сортировка**:
   - Фильтрация только опасных объектов.
   - Сортировка по дистанции, диаметру, скорости и наименованию.
   - Полнотекстовый поиск по имени и номеру ID.
4. **Персистентный кэш**:
   - Сохранение и извлечение валидных снимков из `localStorage`.
   - Защита от поврежденного JSON и устаревших схем.
5. **Сетевой клиент и mock-загрузчик**:
   - Эмуляция нормального ответа, исчерпания лимита запросов (HTTP 429 Rate Limit) и сбоя сети с таймаутом.
6. **Конвертер валют и серверные маршруты**:
   - Прямой, обратный и перекрестный пересчет курсов.
   - Валидация сумм, чисел с точкой и запятой.
   - Обработка выходных дней ЕЦБ (lookback до 10 дней).
   - Smoke-тесты эндпоинтов `/api/neo` и `/api/rates`.

## Проверка пограничных сценариев в GUI

1. **Некорректная дата (31 февраля)**:
   - В поле даты ввести `2026-02-31`. Появляется четкое русскоязычное сообщение: *«Указана несуществующая календарная дата (например, 31 февраля)»*. Кнопка «Получить данные» мгновенно блокируется.
2. **Сбой сети (Offline)**:
   - Загрузить данные за любую дату.
   - Отключить сеть или сымитировать сбой: приложение выводит сообщение об ошибке и отображает баннер: *«Доступен ранее сохраненный снимок за YYYY-MM-DD»* с кнопкой мгновенного применения.
3. **Пустые дни каталога**:
   - Запросить дату без зафиксированных пролетов (или в глубоком прошлом). Приложение корректно сообщает о нулевом количестве объектов и предлагает восстановить последний сеанс.
4. **Потенциально опасные объекты**:
   - Переключить фильтр *«⚠️ Только опасные»*: в сетке остаются исключительно объекты с флагом `is_potentially_hazardous_asteroid === true` со светящейся тревожной рамкой.

- `main` — стабильная ветка со слиянием через PR merge-коммиты.
