# Конвертер валют · Лабораторная №3

Локальное веб-приложение на русском языке: 10 валют, историческая дата, перестановка валют, источник и дата курса, работа с сохранённым ответом при сбое сети.

## Запуск

Нужен Node.js 22+ (рекомендуется 24). Сторонних зависимостей и API-ключей нет, `npm install` не нужен.

```powershell
cd "C:\Users\Marc\Desktop\konvert valute"
npm start
```

Открыть **http://127.0.0.1:3000** в браузере. Остановка — Ctrl+C в терминале.

Если порт занят:

```powershell
$env:PORT = '3001'
npm start
```

В таком случае адрес будет http://127.0.0.1:3001. Кэш привязан к адресу браузера: `localhost`, `127.0.0.1` и разные порты имеют отдельные хранилища. Не открывайте index.html напрямую через file://.

## Тесты одной командой

```powershell
npm test
```

22 теста: парсинг API, прямое/обратное/перекрёстное направления, одинаковые валюты, валидация суммы и даты, пустые/повреждённые ответы, отсутствие сети, таймаут, восстановление/повреждение/недоступность кэша, HTTP-сервер. Сеть не требуется. CI запускает ту же команду.

## Как пользоваться

1. Ввести положительную сумму до 1 трлн, не более двух знаков после точки или запятой.
2. Выбрать исходную и целевую валюты, при необходимости дату.
3. После загрузки курсов нажать «Конвертировать». Стрелки между списками меняют валюты местами.
4. Проверить фактическую дату курса, источник и режим справа. При любом изменении ввода старый результат скрывается.

Курс: Frankfurter v2, провайдер ECB. Доступны EUR, USD, GBP, CHF, JPY, CAD, AUD, CNY, PLN, SEK. Для некоторых старых дат отдельные валюты недоступны. MDL и RUB в выбранный набор не входят.

Формула: `сумма / курс_исходной_к_EUR * курс_целевой_к_EUR`. Для одинаковых валют возвращается исходная сумма. Промежуточное округление отсутствует; результат JPY отображается без десятичной части, остальные — с двумя знаками. Справочный расчёт не учитывает банковские комиссии.

## Проверка пограничных сценариев в GUI

- **Выходной:** выбрать 18.10.2026. При реальном ответе API получен курс 16.10.2026; предупреждение объясняет выбор последней опубликованной даты. Если ответ — пустой массив, сервер ищет назад максимум 10 дней. При сетевой ошибке этот поиск не выполняется.
- **Неверная сумма:** поочерёдно ввести пустую строку, 0, -10, abc. У поля появляется ошибка, кнопка неактивна. `125,50` допустимо.
- **Одинаковые валюты:** USD → USD, сумма 125,50. Результат 125,50 USD.
- **Нет сети и кэш:** сначала загрузить реальный курс, остановить сервер, отключить внешнюю сеть, снова запустить сервер и обновить страницу в том же браузере и по тому же адресу. После ошибки нажать «Использовать сохранённый курс». Режим и дата явно указывают кэш.
- **Нет кэша:** в новом профиле браузера/после удаления данных сайта повторить предыдущий сценарий. Будет понятная ошибка, конвертация недоступна.
- **Историческая дата:** с кэшем от 20.10.2026 запросить 18.10.2026 без сети. Более новый кэш не предлагается.

Кэш — последний валидный ответ в localStorage, ключ `currency-lab:rates:v1`. Хранилище переживает закрытие вкладки и перезапуск сервера. Если браузер запрещает сохранение или квота исчерпана, появляется предупреждение, текущий ответ остаётся в памяти. При выключенном локальном сервере загрузка самой страницы не предусмотрена; при недоступном интернете локальный сервер должен продолжать работать.

## Структура и учебный процесс

- `.specify/memory/constitution.md` — принципы.
- `specs/001-currency-converter/` — требования, план, задачи, проверка согласованности, созданные до кода.
- `public/` — интерфейс, расчёт, валидация и кэш.
- `lib/rates.js`, `server.js` — источник данных и локальный сервер.
- `tests/` — unit- и HTTP-тесты.
- `REPORT.md` — фактический отчёт и ограничения.
- `docs/ANTIGRAVITY.md` — команды Spec Kit/Copilot, передача Antigravity и порядок PR.
- `docs/cache-preview.png` — снимок проверенного расчёта из кэша.

Спецификации сохранены отдельным коммитом **раньше реализации**. Ветки: `specs/currency-converter`, `feat/currency-converter`, `test/currency-converter`. Основная ветка не содержит слияний: удалённый GitHub-репозиторий не предоставлен, PR не создавались. Текущая ветка тестов содержит всё приложение.
