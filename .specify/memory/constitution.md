# Конституция проекта

Версия 1.0 · 21.10.2026

1. Сначала требования, план и задачи, затем код. Изменения требований документируются.
2. Обязателен доступный графический интерфейс на русском языке, управление клавиатурой и адаптивность.
3. Данные только из реального источника. Показывать дату курса и источник; не выдавать кэш за свежий ответ.
4. При сбое сети сохранять последнее успешное состояние, предлагать кэш явно. Ошибки не должны приводить к падению.
5. Расчёт, проверка ввода и разбор ответа отделены от DOM и покрыты unit-тестами.
6. Локальный запуск и тесты не требуют платных сервисов или секретных ключей.
7. Раздельные ветки спецификаций, реализации и тестов. Слияние main — через реальные GitHub PR.
8. Отчёт отражает только фактические инструменты, проверки и вмешательства. Не выдумывать использование моделей или PR.

Происхождение: документ написан в Codex в структуре Spec Kit; CLI Spec Kit и Copilot в этой сессии не запускались.
